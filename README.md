# Conference Website

A conference website built with HTML.

## Technologies
- **Language**: HTML

## Purpose
Create an informational website for a conference event.

## Features
- Event information and schedule
- Conference committee listings
- Call for papers
- Contact information
- Pricing and registration
- Program schedule
- Project showcases
- Responsive HTML structure

## Pages
- **index.html** - Main landing page
- **comitee.html** - Committee information
- **call for paper.html** - Paper submission details
- **contacts.html** - Contact information
- **pricing.html** - Registration pricing
- **program.html** - Conference program and schedule
- **projects.html** - Featured projects

## Usage
Open in a web browser to view conference information and details.
